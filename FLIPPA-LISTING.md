## Title

## One-line hook

A finished, white-label real estate website with a full agent dashboard.

## Summary

PropDrive is a complete, ready-to-launch realtor website with a built-in admin
dashboard. An agent, broker, or agency can change the logo and colors, add
their listings, and have a professional site live in a day. Everything a real
estate site needs is already built: property listings with a map, lead capture,
appointment requests, testimonials, a home valuation request, and a mortgage
calculator. No coding is needed to run it day to day.

This is a clean, modern codebase, not a half-finished startup. It is built on
Next.js, React, and Supabase, deploys free on Vercel, and costs about $3 a
month to run plus a domain.

## What you get

- A polished public website: homepage with a rotating hero, featured listings,
  agent section, and testimonials.
- Property listings with search, filters, photo galleries, and an interactive
  map. No paid maps API required.
- A full admin dashboard to manage listings, leads, appointments, branding,
  testimonials, and site content from one place.
- White-label branding: swap the logo, colors, agent name, and brokerage and
  the whole public site updates.
- Lead capture everywhere: contact form, schedule a showing, home valuation
  request, and "save this home", all flowing into the Leads manager.
- Optional AI assist: connect an OpenAI key to draft listing descriptions,
  testimonials, and banner copy. Fully optional, bring your own key.
- Setup documentation included.
