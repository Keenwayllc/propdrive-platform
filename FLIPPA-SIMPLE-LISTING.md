# Realtor Website With Admin Dashboard

## Short description

A clean Next.js and Supabase realtor website with backend dashboard. Includes
property management, lead capture, appointments, branding controls,
testimonials, and a website editor. Built for agents, brokers, agencies, or
buyers who want a ready-to-launch real estate website platform.

## What it is

Launch a professional realtor website with a built-in admin dashboard. Manage
listings, leads, appointments, branding, testimonials, and website content from
one clean backend. No code required to run it day to day.

## Included

- Domain-ready website

- Admin dashboard
- Property manager

- Branding controls
- Website editor
- Testimonials manager
- Setup documentation

## Admin dashboard

- Overview: total leads, active listings, upcoming appointments, recent leads, quick actions
- Leads: name, email, phone, lead type, message, property interested in, status
- Appointments: name, email, phone, property, date, time, notes, status
- Properties: add, edit, delete, photo uploads, price, address, beds, baths, square feet, description, status
- Website Editor: company name, hero title and subtitle, phone, email, about, footer text, social links
- Branding: logo, primary color, accent color, agent name, agent photo, brokerage name
- Testimonials: add and manage client quotes shown on the homepage
- Settings: account and security

## Public website

- Homepage with hero, featured listings, agent section, and testimonials
- Property listings with search, filter, photo galleries, and a map
- Home valuation request and mortgage calculator
- About and contact pages with lead capture and a schedule-a-showing form
- Privacy and terms

## Tech

- Next.js and React (App Router, TypeScript)
- Tailwind CSS
- Supabase (Postgres, Auth, Storage)
- Vercel hosting
